# SidorovaES_25_diplom_part2

Тест на проверку кода ответа 200 при получении данных о созданном клиентом заказе по его номеру (ручка /api/v1/orders/track) с помощью API Яндекс Самокат

- Для запуска теста должны быть установлены пакеты pytest и requests
- Для наглядности кода и информативного скриншота все параметры отражены в одном файле main_ses.py
- Тест включает одну позитивную проверку на статус кода
